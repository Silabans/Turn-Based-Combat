# Turn-Based-Combat
A turn-based games with different classes and status effects

## How to Play
Enter a number from 1 to 3 to attack, parry, or perform your signature move

## Game Features
1. Status Effects
2. Attacking and Parrying
3. Multiple Class Types

## Python Features Used
1. Classes & Subclasses/Class Children
2. Abstract Base Class (abc) module
3. Luck-based Stats and Attacks
